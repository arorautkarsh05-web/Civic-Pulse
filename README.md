# Civic-Pulse 🏛️⚡

A modern civic risk and urban operations desk that turns civic issue reporting, public risks, and complaint clustering into clear municipal action.

## 🚀 Features

- **Monsoon Operations Desk**: Calm, editorial command-center UI turning civic risk data into real-time public actions.
- **Issue Tracking & Escalation**: Interactive citizen reporting, geotagged complaints, and municipal dispatch workflows.
- **Explainable Risk Intelligence**: Evidence-based complaint clusters, location heatmaps, and predictive incident alerts.
- **Modern Full-Stack Architecture**: React 19, TypeScript, Tailwind CSS, Vite, Express, Drizzle ORM, and Radix UI.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS, Radix UI primitives, Lucide React, Wouter
- **Backend**: Node.js, Express, TypeScript, TSX
- **Database & ORM**: Drizzle ORM
- **Tooling**: Vite, Vitest, Prettier

## 📦 Getting Started

### Prerequisites

- Node.js (v18+)
- pnpm (recommended) or npm / yarn

### Installation

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build

# Start production server
pnpm start
```
